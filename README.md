# fedora-homelab
Homelab Project for self-hosting services

Documentation of a Fedora Linux workstation configured as a small self-hosted lab environment.

## Objectives

- Install and configure Fedora Linux
- Develop practical Linux administration skills
- Configure network connectivity
- Troubleshoot DNS and routing
- Configure firewall rules
- Deploy self-hosted services
- Learn containerized service deployment

## Environment

- OS: Fedora Workstation
- Hardware: Acer Aspire A315-24P
- Network: Wi-Fi
- Container platform: Docker
- Services: Pi-hole

## Networking

Tools used during troubleshooting include:

- nmcli
- ip
- ping
- tracepath
- resolvectl
- ss

## Containerization

Docker is used to deploy self-hosted services while developing practical experience with:

- Containers
- Port mappings
- Docker networking
- Docker Compose
- Service configuration
